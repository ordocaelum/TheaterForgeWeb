# theaterforge.com

Public website for **TheaterForge LLC**, a Utah limited liability company.

**This repository is the only source of truth for the live site.** It is served at
`www.theaterforge.com` through GitHub Pages (see `CNAME`). Edit here; do not edit a copy
elsewhere and expect it to reach the site.

Single static page. No build step, no dependencies, no external scripts, stylesheets or
fonts. Inline CSS and inline SVG only.

| File | Purpose |
|---|---|
| `index.html` | The site, self-contained |
| `TheaterForge_Capability_Statement.pdf` | Capability statement, current revision |
| `favicon.png`, `logo.png` | Brand assets |
| `CNAME` | Custom domain binding for GitHub Pages |

## Before changing anything

Content rules, disclosure constraints and the page plan live in the business records
repository at `TheaterForge_LLC/06_BUSINESS_DEVELOPMENT/06D_MARKETING_COLLATERAL/website/`:

- `WEBSITE_UPDATE_SPEC.md` — what may and may not appear on this site
- `DEPLOY.md`, `LAUNCH_RUNBOOK.md` — deployment procedure

**The capability statement is the disclosure ceiling.** Nothing on this site may exceed what
it discloses. No real system designations, no trade secrets in any image, no claim stated
more strongly here than in the capability statement.
